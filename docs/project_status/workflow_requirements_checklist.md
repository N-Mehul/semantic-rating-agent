# Workflow Requirements Checklist (Digital Persona pipeline)

Workflow: Human Survey Data -> Digital Persona Creation -> Construct-Specific Prompt -> LLM -> Synthetic Text Response -> Sentence Embedding -> Comparison with Five Likert Anchor Statements -> Similarity-to-Probability Conversion -> Expected Likert Score.

Statuses: **Done** (implemented and tested), **Done, blocked on data** (software complete; needs real generated responses or unavailable materials), **Blocked** (cannot be done without an approved input).
Audit result after the final software pass; all items were checked against files and tests on disk.
