# Steps 5-7: Pilot Synthetic Responses, SSR Scoring and Evaluation

Generated by `scripts/pilot_score_and_evaluate.py`. Everything below is a **pilot** (40 synthetic answers) and a **proxy-based** check, not validation of a construct.

## Step 5: generation
- 4 personas x 10 synthetic respondents = 40 (`data/pilot/synthetic_respondent_specs.jsonl`, sampled with seed 20261028 from each persona's marginals by `scripts/pilot_make_specs.py`; attributes are sampled independently so some combinations are odd, e.g. a low-price iPhone).
- **Blocker / deviation:** no LLM API key was available, so the language model (claude-sonnet-5-5, working inside this Claude Code session) wrote the 40 answers by hand from `data/pilot/generation_prompts.md`; they are stored verbatim in `scripts/pilot_write_responses.py` and `data/pilot/synthetic_responses.jsonl`. This is reproducible only by re-using the saved texts, not by re-running code. The prompts forbid numeric ratings; no rating was produced by the model.
- Not blind: the author had seen overall and persona-level Q21 summaries in Step 4 before writing. The texts were written from profile attributes only and not tuned to match them, but that cannot be proven, so synthetic-vs-human agreement is weak evidence.

## Step 6: scoring
- Canonical `cosine_similarities`, `similarities_to_pmf`, `expected_rating` from `canonical_ssr.py` (unmodified; sha256 in `ssr_config.json`). The language model gave no numbers.
- **Deviations from the paper:** (1) encoder is the local `sentence-transformers/all-mpnet-base-v2`, not OpenAI text-embedding-3-small; (2) **one** approved anchor set (Behavioral Intention, flagged `PROPOSED_DOMAIN_ADAPTATION_NOT_ORIGINAL_MAIER_ANCHOR`) instead of six, so there is no averaging across sets; (3) the anchors concern continuing to use the current phone while Q21 asks about buying the same brand again, so the match is imperfect.
- Anchors used: 1: I do not intend to continue using my current smartphone.; 2: I am unlikely to keep using my current smartphone in the near future.; 3: I am undecided about whether I will continue using my current smartphone.; 4: I intend to continue using my current smartphone for the foreseeable future.; 5: I am certain I will continue using my current smartphone unless I need to replace it.
- Outputs: per-response similarities, 5-point PMF, expected rating, rating SD and PMF entropy in `ssr_scores_human_q26.csv` and `ssr_scores_synthetic.csv`.

Interpretation (mine): rank agreement shows whether SSR orders answers in line with the stated intention; absolute agreement (MAE, argmax) depends on calibration, which was not attempted. The min-subtracted PMF from a general-purpose encoder tends to give compressed expected ratings, so rank metrics come first. Q21 is self-report on a different construct (brand rebuy) than the anchors (continued use), and Q26 text mixes a worth-the-price question with the rebuy question; neither is ground truth.

## Limitations
1. 40 synthetic responses, 10 per persona: confidence intervals are wide and the persona comparison is exploratory.
2. Hand-authored generation; not blind to Step 4 summaries; not reproducible by code.
3. Single proxy anchor set and a non-paper encoder: not a faithful reproduction of the paper's pipeline and not calibrated.
4. Q21/Q26 pairing is a proxy; the survey does not measure or validate UTAUT2 constructs.
5. The sample is mostly young students; no claim is made about other populations.
6. Many human Q26 answers are one word ("Yes"), giving SSR little to work with.
